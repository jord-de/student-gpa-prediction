# Student Social Media Usage and
# Academic Performance Prediction

## Project Overview

This project uses Machine Learning to predict
university students' GPA based on their social
media usage and academic-related characteristics.

## Dataset

The dataset contains 2,000 student records
and 10 columns.

## Machine Learning Methods

1. Linear Regression
2. Random Forest Regression

## Target Variable

GPA

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

## Deployment

Streamlit Community Cloud
